Arquitectura del Proyecto

Modern Angular 21 con Arquitectura Hexagonal.

Aplicación de referencia empresarial que demuestra cómo desacoplar las reglas de dominio, los casos de uso y la infraestructura externa aplicando el patrón de Puertos y Adaptadores.

Propósito y Filosofía de Diseño

Este proyecto sirve como estándar arquitectónico para aplicaciones frontend escalables y mantenibles en Angular. En lugar de acoplar la interfaz y los componentes directamente a servicios HTTP o librerías externas, el núcleo de negocio permanece completamente aislado.

Aplicando Domain-Driven Design (DDD) táctico y Puertos y Adaptadores, las invariantes de negocio se validan en entidades ricas, y la persistencia se realiza a través de contratos intercambiables (adaptador en memoria Mock vs. API REST en vivo).

El desarrollo sigue las directrices más recientes de Angular: componentes standalone, reactividad granular con Signals, detección de cambios OnPush, y suite completa de pruebas unitarias.

Diseño de Software

Arquitectura Hexagonal (Puertos y Adaptadores)

La aplicación aísla el núcleo de negocio de los detalles técnicos del exterior mediante puertos (interfaces) y adaptadores (implementaciones concretas). Esto mantiene la lógica libre de dependencias de frameworks o librerías HTTP.
